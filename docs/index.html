Board Layout & Cutting Optimizer

Generate an actual 2D cutting layout for every board before you touch the saw. Kerf-aware guillotine cutting with grain and defect constraints, five scoring strategies, and printable SVG / PDF cutting sheets plus CSV exports — the missing link between a cut list and the saw.

TypeScriptNode.js ≥ 18MIT License14 tests

Part of the open-source BoardFootCalc desktop tool suite — the same board-foot math as the online lumber calculators, offline and scriptable on your own machine.

Features

  • Real 2D guillotine layout — parts are placed on each board, every cut splits the remaining free rectangles into two, and each cut consumes the kerf width (default 1/8").
  • Defect zones — free space is cut around marked defect rectangles; parts never land on a defect.
  • Grain & edge constraints — vertical-grain parts and edge-required parts (one-clean / two-clean) are never rotated when the grain constraint is on.
  • 5 strategies — max-yield, min-waste, min-cuts, grain-priority, balanced.
  • Trim / joint / plane allowances — cut-to-size logic for real workshops.
  • Offcut policy — minimum offcut length worth keeping, leftovers counted in yield.
  • Exports — SVG cutting sheets (true scale, labeled parts, defect marks), PDF cutting plan (one page per board + cut sequence), CSV placements / cut-sequences / summary, full JSON.

Quick start

npm run demo
bfc-cut plan --boards boards.csv --parts parts.csv --strategy balanced

Full CLI reference, input formats and design notes are in the repository README.
